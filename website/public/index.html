FAQ

Windows warns me during install. Is it safe?Windows warnt beim Installieren. Ist das sicher?

Converta isn't signed with a paid certificate (yet), so SmartScreen shows “Unknown publisher”. Click “More info” → “Run anyway”. The full source code is on GitHub if you want to check it.Converta ist (noch) nicht mit einem kostenpflichtigen Zertifikat signiert, deshalb zeigt SmartScreen „Unbekannter Herausgeber“. Klick auf „Weitere Informationen“ → „Trotzdem ausführen“. Der komplette Quellcode liegt auf GitHub, wenn du ihn prüfen willst.

I can't find Converta in my right-click menu.Ich finde Converta nicht im Rechtsklick-Menü.

On Windows 11 it's in the classic menu: click “Show more options”, or hold Shift while you right-click. It only appears on file types Converta supports.Unter Windows 11 steht es im klassischen Menü: „Weitere Optionen anzeigen“ klicken oder beim Rechtsklick Shift halten. Es erscheint nur bei Dateitypen, die Converta unterstützt.

What do I need for Word, Excel and PowerPoint?Was brauche ich für Word, Excel und PowerPoint?

Microsoft Office or the free LibreOffice. PDF → Word works without either.Microsoft Office oder das kostenlose LibreOffice. PDF → Word funktioniert auch ohne.

Why does my first video conversion download something?Warum wird beim ersten Video etwas heruntergeladen?

Converta uses FFmpeg for audio and video. To keep the installer small, it's downloaded once the first time you need it (about 110 MB, checksum verified).Für Audio und Video nutzt Converta FFmpeg. Damit der Installer klein bleibt, wird es beim ersten Bedarf einmalig geladen (ca. 110 MB, Prüfsumme wird kontrolliert).

How do I uninstall Converta?Wie deinstalliere ich Converta?

Settings → Apps → Installed apps → Converta. The menu entry is removed with it.Einstellungen → Apps → Installierte Apps → Converta. Der Menü-Eintrag wird dabei mit entfernt.

Your next file is one right-click away.Deine nächste Datei ist nur einen Rechtsklick entfernt.
