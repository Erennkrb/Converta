# Product

## Platform

web

The design surfaces are the distribution website (`website/public`, converta.erenk.de) and the small Windows windows the app itself shows (Tk: progress window, frame picker, message boxes). The product's main "interface" is the Windows Explorer right-click menu, which follows Windows' own look and is not styled.

## Users

All Windows users equally, with no single primary segment: people who occasionally need a quick format change and don't want an online converter, creators and makers (images, video, 3D printing), and students/office users (PDF ↔ Word, Office → PDF). Their job is to turn a file they already have into the format they need without opening another program.

## Product Purpose

Converta converts files straight from the Windows Explorer right-click menu: right-click → Converta → pick a format, and the new file appears next to the original. Success means the visitor installs it, it shows up in their right-click menu, and conversions just work without thinking about it.

## Positioning

Free and open source is the lead differentiator: no ads, no subscription, code public on GitHub (Erennkrb/Converta, AGPL-3.0). Supporting truths that also hold: it lives in the right-click menu instead of being an app or website, it runs fully offline with no uploads, accounts or tracking, and one tool covers images, audio, video, documents, 3D models and CAD.

## Operating Context

- Install: unsigned Inno Setup wizard (`Converta-Setup-<version>.exe`, ~75 MB) from GitHub Releases; the site's download button resolves the latest release via the GitHub API. Windows SmartScreen shows "unknown publisher" until the installer is code-signed.
- Use: on Windows 11 the entry sits in the classic menu ("Show more options" / Shift + right-click). Selecting several files converts them in one run.
- Long conversions show a progress window; animated images and videos open a frame picker when the target holds a single picture.
- FFmpeg is downloaded once on the first audio/video conversion (~110 MB, SHA-256 verified).
- Word/Excel/PowerPoint conversions need Microsoft Office or the free LibreOffice.

## Capabilities and Constraints

- Formats: images (PNG, JPG, WEBP, AVIF, BMP, GIF, TIFF, ICO, PDF), audio (MP3, WAV, FLAC, OGG, M4A, OPUS, AAC, WMA), video (MP4, MKV, WEBM, MOV, AVI, GIF, audio extraction, single frames), PDF (Word, TXT, page images), Office (Word, Excel, PowerPoint ↔ PDF/ODF), 3D models (STL, OBJ, 3MF, PLY, GLB, OFF), CAD (STEP/IGES → meshes in millimetres), DXF (PDF, SVG, PNG). Source of truth: `converta/formats.py`.
- Never overwrites: output gets a free name next to the original.
- Windows 10/11, 64-bit only. No DWG support.
- Website is static HTML/CSS served by a Cloudflare Worker (`website/wrangler.jsonc`); the installer is too large for Cloudflare and lives on GitHub Releases.

## Brand Commitments

- Name: Converta.
- Logo: rounded square in solid Windows accent blue (#005FB8) with two white arrows in a cycle (`assets/converta.png`, `assets/converta.ico`, generated by `tools/make_logo.py`). Used as app, installer and site icon. The earlier blue → violet gradient was dropped by the owner as "AI slop"; no gradients in the brand.
- Voice: casual and direct. English is the main language for everyone; German is available through the visible DE/EN switch and remembered once chosen.
- Website theme: dark by default, light available through the theme switch.

## Evidence on Hand

- Real product: release v1.2.0 on GitHub, live site, open-source repo, full format list.
- No testimonials, user counts, download numbers, press, reviews or benchmarks exist; future work must not invent them.
- No product screenshots or screen recordings exist yet; the site currently uses a CSS-built illustration of the right-click menu.

## Product Principles

1. Free and open, visibly: no ads, no accounts, no upsell, and the source is always one click away.
2. The right-click menu is the product; anything outside it (windows, site) exists to get people there or to stay out of the way.
3. Nothing leaves the PC and nothing gets overwritten; say so plainly.
4. Honest about friction: SmartScreen warning, FFmpeg download and the Office/LibreOffice requirement are stated up front, not hidden.
5. One tool for everyone: no feature or wording should assume a single kind of user.
